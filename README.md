# Class Clinic — Appointment Scheduler

React + PostgreSQL appointment scheduling app for Class Clinic dental department.

## Stack
- **Client:** React + Vite
- **Server:** Node.js + Express + Prisma ORM
- **Database:** PostgreSQL

## Local setup
1. Install Node.js, npm, and PostgreSQL
2. Clone this repo, run `npm install` in server/ and client/
3. Set up the database and .env
4. Run migrations, seed, then dev servers

See `server/README.md` and `client/README.md` after scaffolding.
